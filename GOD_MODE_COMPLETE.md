## 🚀 Quick Start

### 1. Start Everything:

```bash
./scripts/start-all.sh
```

This single command:
- ✅ Checks environment and dependencies
- ✅ Starts Python agents (Terminal & SDK on ports 8001/8002)
- ✅ Initializes database
- ✅ Launches main platform (port 5000)
- ✅ Activates Master Orchestrator
- ✅ Enables Telegram bot

### 2. Connect Telegram:

1. Ensure your `TELEGRAM_BOT_TOKEN` is set in your `.env` file.
2. Open Telegram and search for your bot by its username (e.g., @YourBotName).
3. Send `/start` to register
4. Send `/help` to see all commands
5. **Send `/initall` to initialize God Mode**

### 3. You're Done!

Now just talk to your bot naturally:
- "Buy 100 shares of AAPL"
- "Check all wallet balances"
- "Start all trading bots then analyze performance"
