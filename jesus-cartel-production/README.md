# KVE FLP Organizer
Find all `.flp`, normalize folders into `INBOX\ProjectName`, gather audio into `Audio\`, and write `manifest.json` for each project.

### Quick start
1) Open this folder in Command Prompt
2) `pip install -r requirements.txt`
3) `python kve_flp_organizer.py --scan D:\ C:\Users\You\Music --out D:\KingdomProjects\INBOX`
   - Or double‑click `run_scan.bat`

Then run your **KVE Watchdog v2** against `D:\KingdomProjects\` to process stems/ premixes.
