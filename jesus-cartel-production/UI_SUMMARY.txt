📡 API INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

All UIs connect to backend API:
  • GET /api - API information
  • GET /health - Health check
  • GET /api/releases/latest - Latest releases
  • GET /api/releases/featured - Featured releases
  • GET /api/releases/:id - Specific release
  • POST /api/releases/:id/like - Like release
  • POST /api/releases/:id/stream - Track stream
  • GET /api/events/upcoming - Upcoming events
  • GET /api/events/featured - Featured events
  • GET /api/events/:id - Specific event
  • POST /api/publish/song - Publish song
  • POST /api/wallet/create - Create wallet
  • POST /api/wallet/import/mnemonic - Import wallet
  • GET /api/wallet/:address/balance - Check balance
  • POST /api/transaction/send - Send transaction
  • GET /api/networks - Supported networks
